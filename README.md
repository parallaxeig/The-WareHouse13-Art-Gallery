# Digital NFT Art Gallery PWA

This project is a Progressive Web App (PWA) for a digital NFT-based Art Gallery with VR/AR capabilities.

## Features
- Upload high-resolution digital artwork (PNG, SVG, etc.)
- Mint NFTs linked to artwork on blockchain
- Wallet integration including One Key hardware wallet
- Immersive VR/AR gallery experience
- PWA features: offline support, installable, responsive design

## Project Structure
- /frontend: React app with PWA setup, wallet connection, upload UI, gallery display, VR/AR components
- /backend: API server for file uploads, metadata, minting support
- /vr-ar: VR/AR specific components and scenes integrated into frontend or as separate module
- /smart-contracts: (optional) Solidity contracts for NFT minting
